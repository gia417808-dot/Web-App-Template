Dự án cần một bộ đặc tả và quy trình làm việc thống nhất để các agent tiếp tục triển khai mà không mất ngữ cảnh.

Thay đổi:
- Đưa bộ hồ sơ 30 sản phẩm và kế hoạch 5 ngày vào planning/company-kit.
- Thêm hướng dẫn root, prompt Review/Plan/Act/Fix/Verify/Sync và checkpoint.
- Thêm công cụ kiểm tra cấu trúc, inventory và Git preflight.

Kiểm tra cần ghi kết quả thực trước tạo PR:
- Bootstrap verifier: ghi command/exit code của lần chạy trên branch này.
- Application: NOT_RUN; bootstrap chưa có app runtime.

Giới hạn: chưa có 30 workbook/app chạy thật, chưa deploy hoặc mở bán. Mục tiêu PR này là bàn giao cấu trúc triển khai, không xác nhận hoàn thành hệ thống.
