# Hợp đồng triển khai

Chưa có SQL đã áp dụng. CORE phải tạo migration từ schema đã audit; constraints/FK tenant/index/ledger/version và rollback tương thích. Chạy trên DB thử trước, không dùng reset dữ liệu thật.

Trạng thái: chưa hiện thực trong bộ hồ sơ này. Không đánh dấu chạy được chỉ vì thư mục tồn tại.
